# slam — 아직 비어 있는 자리

새 프로젝트를 이 대시보드에 태우는 순서를 여기 적어 둔다. 화면은 **아예 다르게 짜도 된다** —
공용으로 묶인 것은 화면이 아니라 데이터 층이다.

## 무엇이 그대로 쓰이고 무엇을 새로 짜나

| | 그대로 | 새로 |
|---|---|---|
| `core/rosmsg.py` | ✓ ROS 2 타입이면 무엇이든 | |
| `core/mcap_read.py` | ✓ 토픽·프레임 이름만 바꾸면 | 판정 규칙(`judge`)은 프로젝트 것 |
| `core/regress.py` | ✓ 지표 이름만 바꾸면 | |
| `core/lerobot_out.py` | 팔이 있는 과제라면 ✓ | SLAM엔 안 쓴다(조작 데이터 포맷이다) |
| `core/build.py` | ✓ | |
| `dashboard.tpl.html` | | **전부 새로.** 보여줄 것이 다르다 |

즉 고칠 곳은 `project.py` 하나와 화면 하나다.

## SLAM에서 "실좌표 재판정"에 해당하는 것

이 대시보드의 핵심은 *로그가 뭐라고 했는지*가 아니라 *실제로 어땠는지*를 다시 세는 것이다.
pick에서는 "코드는 성공이라 했는데 물체는 통 밖"이었다. SLAM의 같은 자리는 이것이다.

- **추정 위치 대 실제 위치.** Gazebo는 로봇의 참값 자세를 준다. `/amcl_pose`나 `/tf`의
  `map→base_footprint`가 말하는 위치와 참값의 차이가 그대로 판정이다(ATE·RPE)
- **로그는 "정상 추정 중"이라고 찍히는데 오차가 커지는 구간**이 있으면 그게 pick의
  거짓 성공에 해당한다 — 이 화면이 잡아야 할 것
- **폐루프 복귀 전후**를 갈라 봐야 한다. 복도 같은 퇴화 지형은 편도 주행으로는 원리상
  교정이 안 되고, 되돌아와 폐루프가 걸릴 때만 오차가 접힌다. 세대(epoch)를 그 기준으로
  나누면 회귀 탐지가 엉뚱한 데를 가리키지 않는다

## 순서

1. **기록부터 MCAP으로.** 시뮬을 띄우고 `ros2 bag record -s mcap`으로 받는다.
   담을 토픽은 최소 `/tf` `/tf_static` `/odom` `/scan` `/map`, 그리고 참값을 내보내는
   토픽 하나. 참값이 없으면 **재판정 자체가 불가능**하다(pick에서 실제로 겪었다 —
   `capstone-pick`의 남은 일 2번 참고)
2. `python3 dash.py slam probe <파일.mcap>` — 무엇이 읽히는지 먼저 본다
3. `projects/slam/project.py`를 채운다. `capstone-pick/project.py`를 옆에 두고
   같은 칸을 SLAM 값으로 바꾸면 된다. `judge`는 "오차가 임계 이내인가"가 된다
4. `python3 dash.py slam check` — 빠진 설정을 미리 잡아 준다
5. 화면(`dashboard.tpl.html`)을 새로 짠다. pick 것을 복사해 고치기보다
   **빈 화면에서 시작하는 편이 낫다** — 보여줄 것이 겹치지 않는다
   (pick: 관절·집게·물체 높이 / SLAM: 지도·궤적·오차 곡선)
6. `python3 dash.py slam all`

## 브랜치를 팔 것인가 — 파지 말 것

**프로젝트마다 브랜치를 파는 것은 권하지 않는다.** 브랜치는 *언젠가 합쳐질 갈래*를 담는
도구다. 프로젝트별 브랜치는 영원히 안 합쳐지고, 그러면 이런 일이 생긴다.

- `core/`를 고칠 때마다 살아 있는 모든 브랜치에 따로 옮겨 심어야 한다(cherry-pick 지옥)
- 브랜치마다 조금씩 다른 core가 생겨 "어느 쪽이 맞는 코드인가"를 알 수 없게 된다
- 포트폴리오로 낼 때 한 브랜치만 보이면 나머지 작업이 통째로 안 보인다

**디렉터리로 가른다.** 지금 구조가 그것이다 — `projects/slam/`을 추가하면
`main` 하나에 두 프로젝트가 나란히 있고, `core/` 개선이 양쪽에 동시에 먹는다.

브랜치는 **작업 단위**로 판다. 합쳐질 것에만 판다.

```
main                     항상 도는 상태
  feat/slam-project      SLAM 프로젝트 추가 → 되면 main으로
  feat/video-player      낱장 JPEG을 비디오 재생으로 → 되면 main으로
  fix/tf-chain           고치고 바로 main으로
```

기준 한 줄: **"이게 언젠가 main에 합쳐지나?" 그렇다면 브랜치, 아니라면 디렉터리다.**
